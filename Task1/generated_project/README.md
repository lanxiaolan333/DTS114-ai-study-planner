# AI Study Planner

Flask API and website generated by `AI_DLC_Study_Planner_Generator.ipynb`.

## Dependencies

Use the conda environment at the **repository root** (not `requirements.txt`):

```bash
cd ../..   # repository root
conda env create -f environment.yml
conda activate ai_in_se_chapter_04
cd Task1/generated_project
```

## Run locally

```bash
python -m pytest -q -p no:cacheprovider
python app/main.py
```

Open `http://127.0.0.1:5000`

## API keys

Copy `Task1/.env.example` to `Task1/.env` before running the notebook. The Flask app does not need API keys at runtime (static dashboard image and rule-based `/api/plan`).
