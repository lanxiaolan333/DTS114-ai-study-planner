# UML PNG export (manual step)

This notebook auto-generates PlantUML source files:

- `uml_use_case.puml`
- `uml_component.puml`
- `uml_sequence.puml`

Export the PNG previews yourself using the PlantUML website:

1. Open https://www.plantuml.com/plantuml
2. Paste the contents of each `.puml` file
3. Download/save PNG into this folder as:

   - `uml_use_case.png`
   - `uml_component.png`
   - `uml_sequence.png`

Do not overwrite the `.puml` files when exporting PNGs.
