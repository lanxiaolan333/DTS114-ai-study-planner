# AI-DLC Study Planner (DTS114TC Coursework)

AI-powered meta-software development coursework: one Jupyter Notebook generates SDLC artefacts, UML diagrams, a Flask API, a website with an AI dashboard image, tests, Docker configuration, and GitHub Actions CI/CD.

**AI tools in this project:** APIFree (via `Task1/.env`) and LLM prompts inside the notebook. **GitHub Copilot was not used.**

## Repository structure

```text
environment.yml              # Conda environment (replaces requirements.txt)
Task1/
  .env.example               # API template (copy to .env locally)
  AI_DLC_Study_Planner_Generator.ipynb
  generated_project/         # Flask API, website, tests, artefacts
Task2/
  deployment_notes.md
  screenshots/               # commit / CI / deployment evidence
docs/                        # GitHub Pages static site
```

## Environment setup

From the repository root:

```bash
conda env create -f environment.yml
conda activate ai_in_se_chapter_04
```

Run the notebook from `Task1/` (see Environment Variables below).

## Environment Variables

A `.env.example` file is provided under `Task1/`. Personal API keys are not included in the repository for security reasons. The teaching team may use their own APIFree credentials when executing the notebook.

1. Copy `Task1/.env.example` to `Task1/.env`
2. Set `APIFREE_API_KEY` and, if needed, adjust `APIFREE_BASE_URL`, `MODEL_NAME`, and `IMAGE_MODEL`
3. Keep `USE_AI_API=true` to enable LLM and image generation in the notebook

The notebook loads `Task1/.env` automatically. Keys are never written into generated artefacts or committed to Git.

## Task 1 — Notebook and Flask app

| Output | How it is produced |
|--------|-------------------|
| `uml_*.puml` | Auto-generated by the notebook (LLM / fallback) |
| `uml_*.png` | **Manual:** export from [PlantUML](https://www.plantuml.com/plantuml) (see `artifacts/uml_render_instructions.md`) |
| Flask API & website | Generated under `Task1/generated_project/` |

```bash
cd Task1/generated_project
python -m pytest -q -p no:cacheprovider
python app/main.py
```

Open `http://127.0.0.1:5000`
